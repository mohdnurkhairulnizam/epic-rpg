Native Correction

One native visibility setting changed the delivery presentation

The Capacitor local-notifications Android source was patched at the point where EPIC RPG constructs its treasure-timer alert. The change moves the notification from a private to a public visibility classification. [1] [2]

Before
setVisibility(VISIBILITY_PRIVATE)
→
After
setVisibility(VISIBILITY_PUBLIC)
Intended
effect

Public visibility makes the timer alert eligible for lock-screen presentation, aligning the visible prompt with the existing alarm sound.

A visibility correction, not a workflow redesign

Treasure scheduling, custom sound, notification tap handling, and the child-profile return path remain in place.

Android’s API exposes notification visibility at the builder level. Device privacy and battery settings can still affect the final display. [2]
