Notification Delivery Path

The alert flow combines scheduling, sound, and return-to-app behavior

The corrected visibility setting fits into the existing local timer workflow: a claimed treasure creates a native alert, supports the alarm experience, and links back to the relevant child journey.

1
Treasure is claimed
The app stores the reward end time and notification key in its local family data.
2
Native alert is scheduled
The Capacitor bridge schedules the timer with the EPIC alarm sound, status icon, and child payload.
3
Access is prepared
Notification and exact-alarm access are requested when needed; an inexact fallback remains available.
4
Alert returns to the child flow
The delivered notification is eligible for lock-screen presentation. Tapping it opens the relevant child profile.

Release outcome: the timer sound and visible prompt are designed to operate as one family-facing reward moment.

Source: EPIC RPG Android 1.3.2 Release Notes [1]05 / 08
