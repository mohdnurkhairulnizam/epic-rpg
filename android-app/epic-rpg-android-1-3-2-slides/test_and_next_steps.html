Release Gate

Physical-device testing is the final release gate

The build and source checks are complete. Before Google Play preparation, the behavior that matters most must be exercised on an intended Android device with real permissions, a real locked screen, and the device maker’s battery policy.

Locked-screen timer
Start a short treasure timer, lock the phone, and confirm a visible notification plus alarm sound at expiry.
Unlocked timer
Repeat with the display on and confirm the existing notification and in-app sound behavior remains correct.
Permissions and continuity
Allow notifications and precise alarms when requested; then verify NFC, treasure claims, and timer behavior after restart.

Recommended next action: install the debug APK on the target phone and run the locked-screen treasure-timer scenario before proceeding with signing and Play Console submission.

Test the device, not only the build

Android device makers can vary lock-screen privacy, alarm access, and battery-management behavior. A successful build does not substitute for real-device validation.

If alerts are delayed, allow notifications, permit exact alarms, and temporarily remove EPIC RPG from battery optimization for the test.
