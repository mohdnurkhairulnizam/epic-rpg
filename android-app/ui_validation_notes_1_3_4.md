# Quest Arena Visual and Audio Upgrade Validation Notes

The browser preview confirmed that Dashboard now opens with a Family Base / Hero HQ banner and hero cards use the Quest Arena split-panel treatment with a dark adventure header, bright activity label, framed progress area, and stronger pixel borders.

The Leaderboard view no longer renders the redundant all-time token list. It now contains only the Weekly Quest Arena beneath a concise weekly-race banner. The no-activity state correctly remains a tied arena rather than choosing an arbitrary champion.

Quest now uses a Mission Board banner and each quest is rendered as a framed arena inventory card with a mission type label, explicit Quest Reward strip, and aligned Request Quest/Edit actions. Shop uses the matching Treasure Vault treatment with a clear token-cost and timer strip. Both screens retain their existing delete, edit, assignment, and claim actions.

Settings now uses a Game Master banner and dark framed control-board headers for the multiplier, birthday, alert/sound, and badge sections. The sound preference text and test control now identify the expanded pixel-adventure feedback set. The test control continued to dispatch its event without browser UI errors; audible native feedback must be confirmed on an installed Android build because the feedback layer intentionally activates only on Android.
