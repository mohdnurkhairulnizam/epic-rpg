# EPIC RPG Android 1.3.7

## Quest Arena header

The application header now uses the block-built Quest Arena language: a Family Quest Board kicker, controller icon, ore badge, pixel rivets, terrain-panel treatment, and clearer typography hierarchy.

## Emerald Loot Drop

Completed and approved quests can now trigger an **Emerald Loot Drop**, a random bonus token reward. It is enabled by default at a **25% chance** and awards **+3 tokens** by default. In Game Master Settings, the family can turn the feature on or off, set the chance from 5% to 100%, and set the extra-token amount. Quest history records both regular quest tokens and any Emerald Loot Drop tokens.

## Avatar roster status

The picker includes five completed new matching pixel avatars in this interim release, in addition to the existing thirty avatars. The remaining fifteen requested original avatars are explicitly deferred until the image-generation quota resets; they are not shown as unavailable or broken options.

## Validation

TypeScript validation and production build passed. Browser preview confirmed the new header, Emerald Loot Drop settings panel, saved custom reward value, and completed-avatar-only picker.
