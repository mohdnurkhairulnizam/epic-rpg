# EPIC RPG Android 1.3.8

## Emerald Loot Drop layout correction

The Emerald Loot Drop controls were reorganized for phone layouts. Drop chance now has its own label and framed slider row with a separate percentage readout. Bonus tokens now has its own label and full-width numeric field beneath it. This removes the overlapping slider, percentage, and input arrangement reported in the supplied screenshot.

## Avatar rollback

The five new generated avatars added in 1.3.7 did not match the established avatar style, so they have been fully removed from both the picker and Android asset package. The app has returned to its original avatar roster only.

## Validation

TypeScript and production builds passed. Preview validation confirmed the corrected vertical bonus-control layout and the removal of all bonus-avatar references and files.
