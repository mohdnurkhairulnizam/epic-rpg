# EPIC RPG Stable Release 1.3.5

This GitHub revision records the current cross-platform stable release.

| Surface | Stable version | Status |
|---|---:|---|
| Android application | 1.3.5 (`versionCode 9`) | Debug APK and release AAB built successfully. |
| Permanent web companion | Stable Web Companion 1.3.5 | Published at https://epicrpg-etrcq6mh.manus.space. |

The Android and web interfaces now share the Weekly Quest Arena, updated Dashboard, Quest, Shop, Settings, child-profile, and NFC checkpoint presentation. The permanent web companion also supports browser-local pixel-adventure feedback controlled by the existing sound preferences.

Android 1.3.5 source and release notes are retained under `android-app/`. The root `client/` application is the synchronized permanent web source.
